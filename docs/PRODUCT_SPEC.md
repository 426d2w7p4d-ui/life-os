你是一名资深全栈工程师、移动端产品经理、UI/UX 设计师和交互设计师。

请帮我从零开发一个完整、可运行、可在手机上长期使用的个人生活管理应用。

应用名称暂定：

# Life OS

中文副标题：

# 我的生活

日历、任务、大学课程、英语学习、每日复盘、宠物管理、记账、备忘录、纪念日、倒数日、短视频运营客户、视频项目、生活数据

全部整合到一个应用中。

# 一、第一版技术要求

目前不要开发微信小程序。

第一版优先做成：

## 手机端优先的 PWA Web App

要求能够：

- 在 Android 手机浏览器打开
- 在 iPhone Safari 打开
- 添加到手机主屏幕
- 看起来尽量接近真正的原生 APP
- 桌面浏览器也可以正常使用
- 支持响应式布局
- 支持竖屏手机
- 兼容常见手机尺寸
- 支持 iPhone 刘海和底部安全区域

推荐技术栈：

- React
- TypeScript
- Vite
- Tailwind CSS
- Lucide Icons
- Framer Motion 或轻量动画方案
- IndexedDB
- Dexie.js
- React Router

如果有更合适的稳定方案，可以优化，但不要为了炫技使用复杂架构。

代码必须：

- 清晰
- 模块化
- 易维护
- 有完整 TypeScript 类型
- 不出现大量 any
- 有统一的数据层
- 有统一状态管理
- 有错误处理
- 有空状态
- 有加载状态
- 有删除确认
- 有数据校验

# 七十、最后的设计原则

这个 APP 不是：

“功能越多越好”。

而应该是：

“功能很多，但使用起来非常简单”。

永远站在一个完全不懂技术的普通用户角度设计。

能一个按钮解决：

不要三个按钮。

能自动统计：

不要让我手算。

能自动关联：

不要让我重复录入。

能从已有数据得到的信息：

不要再次让我填写。

最终让 Life OS 给人的感觉是：

我不是在管理一个软件。

而是：

它在帮我整理生活。
